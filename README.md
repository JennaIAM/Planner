# Planner

A simple notebook-style monthly planner that installs on your phone.

- One line per day, with the day number and name (1 Sa, 2 Su, 3 M …)
- Doodle your own stamps and mark any day with them
- Tracker columns next to each day: tick, number, letter, word, or your own doodle
- Monthly goals you tick off
- A notes page per month with text, tables and mini doodles

Everything is saved on the phone only. Use ☰ → **Save backup** now and then.

## Put it online (GitHub Pages)
1. Upload all these files to the root of a GitHub repo (keep the `icons` folder).
2. Repo **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
3. Wait a minute, then open `https://<username>.github.io/<repo-name>/`.

## Install on iPhone
Open the link in **Safari** → Share button → **Add to Home Screen**.

## Install on Android
Open the link in **Chrome** → ⋮ menu → **Add to Home screen / Install app**.

## Updating
After changing any file, bump `VERSION` in `sw.js` so phones pick up the new version.
